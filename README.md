# LYASKOVSKY

Корпоративный сайт на Next.js и Go с хранением обращений в PostgreSQL.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и задайте `POSTGRES_PASSWORD`, `NEXT_PUBLIC_SITE_URL`, контактный email и телефон. Для локального Docker запуска используйте `NEXT_PUBLIC_SITE_URL=http://localhost:8088`.
2. Запустите `docker compose up --build -d`.
3. Откройте `http://localhost:8088`. После изменения публичного домена или контактов пересоберите контейнер `web`.

Для отдельной разработки: `npm ci && npm run dev`; API: `cd api && go run .` с доступным `DATABASE_URL`. Next.js перенаправляет `/api/v1/*` на `API_INTERNAL_URL`.

## Перед публикацией

- Укажите реальный домен в `NEXT_PUBLIC_SITE_URL`, контактные данные и сведения об операторе персональных данных в политике конфиденциальности.
- Настройте HTTPS на внешнем reverse proxy или перед Nginx. Не публикуйте PostgreSQL и Go API напрямую.
- Сохраните `POSTGRES_PASSWORD` только в переменных окружения. Делайте резервные копии тома `postgres_data`.
- Форма хранит обращения в закрытой таблице `leads`; публичного API для чтения нет.

## Проверки

`npm run typecheck`, `npm run lint`, `npm run build`, `cd api && go test ./...`, `npx playwright test`.

## Интерактивная версия сайта

- Карта архитектуры показывает учебные примеры платформы, AI-процесса и интеграции; это не кейсы заказчиков и не мониторинг действующей системы.
- Подбор решения передаёт только название направления в `/contacts?service=…`. Сервер проверяет его по списку услуг. Контактные данные не сохраняются в URL или localStorage.
- Для обращения обязательны имя, email, описание и согласие. Компания, телефон и услуга необязательны. При развёртывании этой версии обновите одновременно frontend и Go API: прежний API требует компанию и услугу. Миграция таблицы не нужна.
- `window` получает события `lyaskovsky:conversion`: `solution_selected` (только название услуги), `inquiry_submitted` (отправка запроса), `inquiry_saved` (подтверждённое сохранение). Они подготовлены для подключения измерения, но сами ничего не отправляют во внешнюю аналитику. События не содержат полей формы.
- `node scripts/visual-audit.mjs` проверяет запущенный сайт на localhost:3000: 72 сочетания маршрутов и ширин, 56 состояний подбора решения; сохраняет desktop/mobile скриншоты в `artifacts/`.

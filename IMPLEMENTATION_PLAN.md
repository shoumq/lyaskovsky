# План реализации LYASKOVSKY

## 1. Дизайн и содержание

- Типографический первый экран с асимметричной сеткой и крупным словесным знаком.
- Палитра: тёплый белый `#F5F4F0`, графит `#181818`, тёмный фон `#17191B`, бордовый акцент `#7C2929`.
- Полнострочный список услуг вместо карточек; методология и бизнес-задачи в редакционной композиции.
- Русский деловой текст без неподтверждённых кейсов, цифр и наград.

## 2. Архитектура

- Next.js App Router и Server Components по умолчанию; клиентский код только для формы и мобильного меню.
- Go API `POST /api/v1/leads` с проверкой данных, honeypot и ограничением частоты запросов.
- PostgreSQL для обращений; Docker Compose для приложения, API, базы и Nginx.

## 3. Проверка

- TypeScript, ESLint, production build, Go tests.
- Playwright на desktop Chromium и mobile WebKit: навигация, адаптивность, форма, ошибки JavaScript и доступные элементы.
- Сквозная проверка записи обращения через Nginx и удаления тестовых данных.

## 4. Перед публичным запуском

- Указать настоящий домен и контакты в `.env`.
- Дополнить политику сведениями об операторе персональных данных.
- Настроить HTTPS, резервное копирование PostgreSQL и мониторинг инфраструктуры.

# Проверка редизайна

Концепция: архитектура работающего бизнеса. Графитовые поверхности, янтарные маршруты, холодный светлый фон инженерных пояснений. Карта системы, схема решения и документ этапа образуют общий визуальный язык.

## Изменение сценария

Предложение → интерактивный выбор бизнес-задачи → подход и практическая польза → примеры инженерных решений → результаты этапов → ответы на вопросы → короткая форма.

## Визуальная проверка

Просмотрены реальные скриншоты desktop и mobile. Уменьшена высота карты первого экрана, исправлены соединения узлов и мобильный перенос инженерного заголовка. Вся графика - SVG и CSS, без растровых зависимостей и WebGL. Движение потока ограничено по времени, повторяется пользователем; reduced motion отключает его.

## Достоверность и конверсия

Архитектура явно обозначена как пример. Нет придуманных кейсов, отзывов, показателей или сроков ответа. Подбор решения показывает проблему, подход, пользу и аудиторию. Примеры отказа API и проверки AI объясняют инженерные решения, не выдают их за реализованные клиентские проекты. Контактная форма не требует компанию, бюджет или телефон. Успех показывается только после HTTP 201 с идентификатором обращения. Ошибка сохраняет ввод.

Подготовлены локальные события конверсии без персональных данных. Внешняя аналитика не подключена, изменение конверсии не измерялось.

## Проверки

- Production build, TypeScript, ESLint: успешно.
- Playwright: 24 теста, desktop Chromium и mobile WebKit.
- Go API: тесты пройдены, включая необязательные сведения и отклонение неизвестной услуги.
- 72 сочетания страниц и ширин: 320, 375, 390, 430, 768, 1024, 1440, 1920.
- 56 состояний подбора решения: без переполнения.
- Навигация, клавиатурное управление узлами, выбранное направление в форме, reduced motion, успешный и ошибочный ответы API проверены.

Отправка в production-базу не выполнялась: браузерные проверки используют подмену ответа API, серверная валидация покрыта Go-тестами. Для упрощённой формы необходимо развернуть обновлённые frontend и API вместе.
